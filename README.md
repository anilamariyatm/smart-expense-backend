# Smart Expense Tracker – MEAN Stack

A full-stack personal expense tracking application built using MongoDB, Express.js, Angular, and Node.js.

## Features
✔ Secure User Authentication (JWT)  
✔ Strong Password Validation  
✔ Add / Edit / Delete Expenses  
✔ Category Management  
✔ Dashboard with Bar & Pie Charts  
✔ CSV Expense Import  
✔ Auto Logout for Security  
✔ Profile Management  

## Tech Stack
Frontend: Angular  
Backend: Node.js + Express  
Database: MongoDB  

## Deployment
Currently deployed locally for demonstration. Can be easily deployed to cloud platforms.
